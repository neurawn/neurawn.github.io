Drafts on GitHub

    Save drafts to GitHub

    Each draft is saved as a JSON file in a GitHub repo. Napkin uses a fine-grained access token that is stored only in this browser.

    1. Open github.com/settings/personal-access-tokens/new.
    2. Under Repository access, choose Only select repositories and pick the repo below.
    3. Under Permissions → Repository permissions, set Contents to Read and write. Generate it and paste it here.
